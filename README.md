## 💎 Design & Architecture

- **Stack Technique** : React + Vite + Tailwind CSS v4 + Lucide Icons + Web Audio API.
- **Identité Visuelle** : Palette sombre luxueuse (*charcoal / void black*) avec éclairage d'ambiance émeraude et cyan s'accordant avec le portrait studio officiel de Mohamed Amine.
- **Composants Développés** :
  1. `Navbar.jsx` : Îlot flottant en verre dépoli (`backdrop-blur-xl`), switcher audio synthétisé, badge de bienvenue en Darija (🇲🇦) et menu responsive.
  2. `Hero.jsx` : Titre éditorial, badges de statut animés, présentation Apple-style de la photo avec rim-light, métriques clés (2+ ans, 8+ projets, 100% clean code) et rôles dynamiques.
  3. `SelectedProjects.jsx` : Cartes de projets avec filtres interactifs (Tous, MERN & Node.js, Laravel & PHP, Systèmes & APIs) et boutons d'accès rapide.
  4. `ProjectModal.jsx` : Modale d'architecture logicielle détaillée (schémas, défis, tokens Sanctum, transactions SQL, requêtes temps réel).
  5. `TechEcosystem.jsx` : Matrice par onglets (Frontend, Backend, Bases de données, Sécurité web OWASP XSS/CSRF/CSP, CachyOS Linux, jauges de langues).
  6. `ExperienceTimeline.jsx` : Ligne temporelle du parcours (Stage WLC Marrakech - Revio NFC, YouCode UM6P, Lycée Ryad Ezzahya, e-commerce).
  7. `InteractiveTerminal.jsx` : Véritable émulateur de terminal Linux CachyOS avec commandes interactives (`neofetch`, `about`, `skills`, `projects`, `contact`, `matrix`, `clear`).
  8. `LiveGitHubFeed.jsx` : Synchronisation en direct avec l'API GitHub (`MoAmiine`) pour afficher les dépôts récents avec étoiles, forks et langages.
  9. `ContactSection.jsx` : Boutons de copie rapide en 1 clic pour l'email (`medamine.teljaoui@gmail.com`) et téléphone (`+212 601818233`), avec formulaire direct.
  10. `Toast.jsx` : Notifications contextuelles animées.

## 🚀 Commandes Disponibles

### Lancer le serveur de développement :
```bash
npm run dev
```
Le serveur local se lance instantanément sur `http://localhost:5173`.

### Tester le build de production :
```bash
npm run build
npm run preview
```

## 🌐 Déploiement en Production

### 1. Sur Vercel (Recommandé) :
- Pushez ce dossier sur votre compte GitHub `MoAmiine`.
- Connectez votre repo sur [vercel.com](https://vercel.com).
- Vercel détecte automatiquement Vite + React et déploie en quelques secondes.

### 2. Sur GitHub Pages :
- Ajoutez `"base": "/nom-du-repo/"` dans `vite.config.js`.
- Exécutez `npm run build`.
- Déployez le contenu du dossier `dist/` sur la branche `gh-pages`.
